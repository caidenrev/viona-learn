Kapan Sebenarnya Kita Memerlukan useEffect?

Di React, proses render komponen harus murni dan tidak boleh menghasilkan side effect langsung di badan fungsi. Operasi seperti mengambil data dari API, mengatur timer interval, membaca nilai dari localStorage, atau memperbarui judul dokumen web harus didelegasikan ke Hook useEffect.

push_pin
Catatan Kunci: Siklus Eksekusi

Fungsi di dalam useEffect dieksekusi tepat setelah browser selesai melukis antarmuka layar (render pass), dan akan berjalan ulang hanya jika variabel pada dependency array mengalami perubahan nilai!

code_blocks Contoh Kasus: Counter Sesi Belajar 
import { useState, useEffect } from 'react';

function CounterSesiBelajar() {
  // State untuk melacak jumlah sesi belajar
  const [jumlahSesi, setJumlahSesi] = useState(0);

  // Efek samping: sinkronisasi judul halaman browser
  useEffect(() => {
    document.title = `Belajar Yuk! - Sesi ke-${jumlahSesi}`;
  }, [jumlahSesi]); // Dependensi: hanya jalan ulang saat jumlahSesi berubah

  return (
    <div className="p-4 bg-cream rounded">
      <h3>Target Hari Ini: {jumlahSesi} Selesai</h3>
      <button onClick={() => setJumlahSesi(jumlahSesi + 1)}>
        Tambah Sesi Selesai
      </button>
    </div>
  );
}

Tiga Jenis Dependency Array:

  • radio_button_checked
    Tanpa array dependencies: Efek berjalan di setiap render ulang. Hindari hal ini untuk request API agar tidak looping tiada henti.
  • radio_button_checked
    Array kosong ([]): Efek hanya berjalan sekali tepat saat komponen pertama kali dipasang (mount).
  • radio_button_checked
    Array berisi variabel ([stateA, propB]): Efek akan dipicu ulang ketika salah satu nilainya berganti.
