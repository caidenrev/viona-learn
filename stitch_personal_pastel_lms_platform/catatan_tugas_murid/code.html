Trik CSS Flexbox vs Grid

Flexbox: Fokus 1 Dimensi (baris ATAU kolom). Bagus buat navbar, tombol bergrup, atau tag chips.

CSS Grid: Fokus 2 Dimensi (baris DAN kolom sekaligus). Sempurna untuk layout galeri, dashboard bento, dan binder halaman.
